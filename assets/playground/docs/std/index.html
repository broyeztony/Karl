Standard Library Reference

Exhaustive built-in API reference for current runtime behavior. This page is aligned with interpreter/builtins_*.go and the canonical stream/process specs.

1. Runtime Availability

Karl has two execution environments: CLI/native runtime and browser/WASM bench runtime.

CLI native: full standard library Bench WASM: core language + safe built-ins Bench unsupported: process/sql/signals/httpServe/filesystem streams

18. Non-Obvious Examples

map overloads: constructor vs array transform vs stream stage

let m = map()
let xs = map([1, 2, 3], x -> x * 2)
let ys = read("items.txt", { type: TEXT, }) | lines() | map(_ + "!") | collect()

http overloads: blocking object request vs stream source

let r = http({ method: "GET", url: "https://api.github.com", })
let rows = http("https://example.com/events.ndjson", { type: TEXT, }) | lines() | collect()

run vs proc

let st = run("kubectl", "get", "ns") // blocking capture

let p = proc("kubectl", "logs", "-f", "deploy/api", { stdout: PIPE, stderr: NULL, stdoutType: TEXT, })
let [line, eof] = p.stdout.read()
let final = wait p

stream.read() cursor semantics

let s = read("events.log", { type: TEXT, }) | lines()
let [a, eofA] = s.read()
let [b, eofB] = s.read()
s.close()
let [c, eofC] = s.read() // [null, true]

run overflow mode

let st = run("cat", "huge.log", { maxOutputBytes: 4096, overflow: "truncate", })
log({ truncated: st.outputTruncated, size: len(st.output), })
Canonical semantics are defined in SPECS/stream.md and SPECS/process.md. Next: idiomatic patterns
