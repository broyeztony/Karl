Documentation

Single source of truth for Karl language behavior, runtime semantics, and library APIs. This section is split into formal spec material, standard library reference, and idiomatic patterns.

Version focus: v0.8.x

Specs

Formal, implementation-oriented specification of Karl grammar and semantics. Covers parser grammar (EBNF), expression evaluation, concurrency model, error handling, import/runtime behavior, and determinism rules.

Open /docs/specs

Std

Complete reference for Karl standard library built-ins and method sugars. Includes argument lists, return values, runtime constraints, and environment availability (CLI vs browser runtime).

Open /docs/std

Idiomatic

Concise Karl patterns: destructuring, recover flows, task composition, channel streams, and expressive match + guard style. Each pattern is optimized for readable and compact Karl code.

Open /docs/idiomatic
