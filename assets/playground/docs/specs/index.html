1. Notation

This specification is normative for Karl parser and interpreter behavior. Grammar uses EBNF-style productions. Literal tokens are quoted; non-terminals are lowercase names.

Karl is expression-based: every construct yields a value. Assignment and loop control are expressions, not statements-only forms.

2. Lexical Elements

  • Identifiers: [a-zA-Z_][a-zA-Z0-9_]*.
  • Literals: integers, floats, strings, chars, booleans, null, and unit ().
  • Comments: line comment form // ....
  • Operators include arithmetic, comparisons, assignment operators, &, !&, and ?.
  • spawn is an alias keyword for &; race is an alias for !&.

3. Core Grammar (EBNF)

program              = { statement } ;
statement            = let_stmt | expr_stmt ;
let_stmt             = "let" pattern "=" expr [ ";" ] ;
expr_stmt            = expr [ ";" ] ;

expr                 = assign ;

assign               = logic_or
                     | lvalue assign_op assign ;   // right-associative
lvalue               = IDENT { "." IDENT | "[" expr "]" } ;
assign_op            = "=" | "+=" | "-=" | "*=" | "/=" | "%=" ;

logic_or             = logic_and { "||" logic_and } ;
logic_and            = equality { "&&" equality } ;
equality             = comparison { ( "==" | "!=" | "eqv" ) comparison } ;
comparison           = range { ( "<" | "<=" | ">" | ">=" ) range } ;
range                = sum [ ".." sum [ "step" sum ] ] ;
sum                  = product { ( "+" | "-" ) product } ;
product              = prefix { ( "*" | "/" | "%" ) prefix } ;

prefix               = ( "!" | "-" | "wait" ) prefix
                     | import_expr
                     | spawn_expr
                     | race_expr
                     | if_expr
                     | match_expr
                     | for_expr
                     | break_expr
                     | continue_expr
                     | postfix ;

import_expr          = "import" STRING ;
spawn_expr           = ( "&" | "spawn" ) spawn_target ;
spawn_target         = call_expr | group_expr ;
race_expr            = ( "!&" | "race" ) group_expr ;
group_expr           = "{" [ call_expr { "," call_expr } [ "," ] ] "}" ;

postfix              = primary { call_op | recover_op | member_op | index_or_slice_op | inc_dec_op } ;
call_expr            = primary { member_op | index_or_slice_op } call_op { call_op | member_op | index_or_slice_op | inc_dec_op } ;
call_op              = "(" [ expr { "," expr } [ "," ] ] ")" ;
recover_op           = "?" expr ;
member_op            = "." ( IDENT | "then" ) ;
index_or_slice_op    = "[" ( expr [ ".." [ expr ] ] | ".." [ expr ] ) "]" ;
inc_dec_op           = "++" | "--" ;

if_expr              = "if" expr block [ "else" ( if_expr | block | expr ) ] ;
match_expr           = "match" expr "{" { match_arm [ ";" ] } "}" ;
match_arm            = "case" pattern [ "if" expr ] "->" expr ;
for_expr             = "for" expr [ "with" bindings ] block [ "then" ( brace_expr | expr ) ] ;
bindings             = binding { "," binding } ;
binding              = pattern "=" expr ;
break_expr           = "break" [ expr ] ;
continue_expr        = "continue" ;

primary              = literal
                     | IDENT
                     | "_"
                     | "(" expr ")"
                     | "()"
                     | brace_expr
                     | array
                     | lambda_expr
                     | query_expr
                     | struct_init ;

lambda_expr          = binder "->" expr ;
binder               = pattern | "(" [ pattern { "," pattern } [ "," ] ] ")" ;

brace_expr           = block | object ;
block                = "{" { statement } "}" ;
object               = "{" [ object_entry { "," object_entry } [ "," ] ] "}" ;
object_entry         = IDENT [ ":" expr ] | "..." expr ;

array                = "[" [ expr { "," expr } [ "," ] ] "]" ;
struct_init          = IDENT object ;

query_expr           = "from" IDENT "in" expr
                       { "where" expr }
                       [ "orderby" expr ]
                       "select" expr ;

pattern              = "_"
                     | IDENT
                     | literal
                     | range_pattern
                     | object_pattern
                     | array_pattern
                     | tuple_pattern ;
range_pattern        = literal ".." pattern ;
object_pattern       = "{" [ pattern_entry { "," pattern_entry } [ "," ] ] "}" ;
pattern_entry        = IDENT [ ":" pattern ] ;
array_pattern        = "[" [ array_pattern_items ] "]" ;
array_pattern_items  = "..." pattern [ "," ]
                     | pattern { "," pattern } [ "," "..." pattern ] [ "," ] ;
tuple_pattern        = "(" [ pattern { "," pattern } [ "," ] ] ")" ;

literal              = INT | FLOAT | STRING | CHAR | "true" | "false" | "null" ;

3.1 Object vs Block Disambiguation

{ ... } parses as an object literal when a top-level colon, spread, or trailing comma is present. Otherwise it parses as a block expression. Shorthand-only objects should use trailing comma form, e.g. { x, y, }.

Constraint: spawn/& and race/!& group entries must be call expressions.

4. Evaluation Semantics

4.1 Order

Karl evaluates left-to-right for arguments, array/object entries, and infix operands. Logical && and || short-circuit.

4.2 Truthy / Falsy

Falsy values are: null, false, numeric zero, empty string, empty array/object/map/set. Everything else is truthy.

4.3 Loop Results

  • for ... then ... returns the then expression on normal termination.
  • break expr exits loop with expr directly (bypasses then).
  • break with no value uses then result if present, else unit ().

4.4 Equality

  • ==: identity for composite values.
  • eqv: deep structural equality for arrays/objects/maps.

5. Concurrency Model

Karl concurrency is task-based with channels and explicit waiting. Runtime implementation is cooperative from the language perspective. 

let grouped = & { a(), b(), c() }
let grouped2 = spawn { a(), b(), c() }   // alias
let all = wait grouped

let first = wait !& { slow(), fast() }
let first2 = wait race { slow(), fast() } // alias
  • &/spawn returns a <task>.
  • !&/race resolves first result and cancels losers cooperatively.
  • wait expects a task handle; otherwise runtime error.
  • Channels expose send, recv, done.

6. Error Model

Karl supports recover blocks via postfix ?. Recover receives implicit error object with kind and message. 

let parsed = jsonDecode(raw) ? {
    log(error.message)
    { fallback: true, }
}
  • Recover applies to expressions and recovers runtime or recoverable builtin errors.
  • fail() creates recoverable failures.
  • exit() is terminal and not recoverable.

7. Imports and Modules

import "path" returns a factory function. Calling the factory evaluates module top-level bindings in a fresh module environment and returns exported bindings.

  • Relative paths resolve against importer directory.
  • Non-relative paths resolve against project root.
  • Top-level let bindings are exported.

8. Runtime Snapshot and Context

Process context (argv, environment snapshot, program path) is captured at runtime initialization and shared by spawned tasks.

argv()
Program arguments after -- in karl run.
programPath()
Current script path, <stdin>, or null when unavailable.
environ()
Environment snapshot as ["KEY=value", ...].
env(name)
Environment lookup returning string or null.
