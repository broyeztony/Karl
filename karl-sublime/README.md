# Karl Sublime Text Syntax

Install for Sublime Text (macOS):

1. Open `Preferences -> Browse Packages...`
2. Create folder `Karl` if it does not exist.
3. Copy `Karl.sublime-syntax` into that folder.

Target path:

`~/Library/Application Support/Sublime Text/Packages/Karl/Karl.sublime-syntax`

Then open a `.k` file and select `View -> Syntax -> Karl`.
