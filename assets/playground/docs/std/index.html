Standard Library Reference

This page is the API reference for global Karl built-ins and member-method sugar. Signatures are written in Karl style; nullable return values are explicit.

1. Runtime Availability

Some APIs depend on runtime host capabilities. Browser WASM (bench) does not provide OS file APIs, signal watching, SQL drivers, or server sockets.

CLI/runtime: full std Bench WASM: pure/runtime-safe subset Unsupported in bench: file I/O, signalWatch, sql*, httpServe
